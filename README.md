# مدرسة الهدى الثانوية بنين — مشروع APK يعمل دون إنترنت

## محتويات المشروع
- `main.py`: تطبيق Flet عربي لإدارة الطلاب والدرجات.
- قاعدة البيانات `students.db` تُنشأ تلقائياً في مساحة التطبيق المحلية.
- إضافة/تعديل/حذف الطلاب والبحث عنهم.
- استيراد ملفات Excel بصيغة `.xlsx` وتصدير البيانات.
- إنشاء شهادة درجات PDF.
- GitHub Actions workflow لبناء APK ورفع الناتج كـ Artifact.

## مهم قبل البناء
1. ارفع جميع محتويات هذا المجلد إلى مستودع GitHub جديد أو مستودع مشروعك.
2. تأكد أن الملف `pyproject.toml` موجود في جذر المستودع.
3. افتح تبويب **Actions**، ثم اختر **Build Huda School APK** واضغط **Run workflow**.
4. بعد نجاح البناء افتح تشغيل الـ workflow ثم قسم **Artifacts** وحمّل `huda-school-apk`.
5. انقل APK إلى هاتف Android وثبّته. قد تحتاج السماح بالتثبيت من هذا المصدر.

## البناء يتطلب إنترنت
عملية البناء على GitHub تحتاج الإنترنت لتنزيل Flutter وAndroid SDK والحزم. بعد تثبيت التطبيق، وظائف قاعدة البيانات والبحث وتسجيل الدرجات تعمل دون إنترنت.

## خط PDF العربي
لأفضل نتيجة في شهادة PDF، ضع ملف الخط `Amiri-Regular.ttf` داخل مجلد `assets/`.
المجلد موجود في المشروع لكن الخط لم يُضمّن تلقائياً. من دون الخط قد لا تظهر الحروف العربية متصلة بشكل صحيح في PDF.

## ملاحظات
- الاستيراد يدعم `.xlsx` فقط؛ ملفات `.xls` القديمة يجب حفظها أولاً بصيغة `.xlsx`.
- هذا مشروع أولي جاهز للاختبار، وليس APK مبنياً أو مختبراً على الهاتف بعد.
- لا يحتوي على تسجيل دخول أو نسخ احتياطي تلقائي بعد؛ احتفظ بنسخة من البيانات المهمة.
